# NIR Conformance

This repository is preparing source-bound NIR conformance evaluation. Its current executable surface is repository validation tooling. It has no installed NIR-conformance package, public conformance runner or qualified conformance certificate.

The intended workflow binds complete source, suite, framework, numerical and executor identities. Every required primitive, lane and corner remains visible. Independent references precede verdicts; missing execution cannot become conformant. Unsupported is an explicit scoped result.

Read [Architecture](ARCHITECTURE.md), [validation tooling](validation-tooling.md), [data boundaries](THREAT_MODEL.md) and the [repository boundary decision](adr/0001-repository-boundary.md).
