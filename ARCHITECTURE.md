# Architecture

## Current executable surface

Repository validation tooling, dedicated tests, workflow definitions and native documentation are implemented. No domain suite, numerical reference, framework lane, conformance comparator, certificate or product command is installed. Domain capability, claim and qualified-format inventories remain empty.

## Intended data flow

An earlier complete source catalogue, suite, framework version, numerical profile and execution context fixes every required primitive, lane and corner. Two actual independent reference paths qualify expected results. Real import, export and round-trip executions retain their graphs, inputs, states and traces. Observable-specific comparison produces scoped findings; full native candidates use shared evidence operations and a separate current consumer.

## Ownership and interpretation

NIR Conformance owns semantic conformance to the declared source and realisation. Divergence Harness retains execution and reduction; it supplies a different comparison oracle for its own work. Framework and standard sources remain with their owners. Evidence Manifest Toolkit owns shared evidence operations; Studio renders certificates.

A catalogue entry is distinct from implemented support. A numerical-profile difference is not automatically a standards defect. Read [the documentation architecture](docs/ARCHITECTURE.md).
