# Decision: bind conformance to complete scope and independent references

## Context

Graph parsing and framework support declarations do not establish preserved behaviour. A small passing subset, duplicated references or cancelling round-trip errors can conceal important differences.

## Decision

NIR Conformance owns the declared reference suite, independent semantic oracle, conformance comparison and scoped certificate. Divergence Harness retains execution and reduction. Frameworks, shared evidence and downstream consumers retain their own implementations and admission.

## Consequences

Repository controls can be qualified before a suite exists. Every actual source, framework, numerical or suite change creates a distinct admitted scope. Unsupported and missing evidence remain visible, including the project's own bridge. No fork of the standard or second execution framework is introduced.
